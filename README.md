# BongyFilms - Android Movie Management App

A comprehensive Android application for managing your personal film collection using the OMDb API and SQLite database.

## Features

* 🎬 Start page with welcome\_background.jpg image
* 📋 Main window displaying all films from SQLite database
* 🔍 Search films by title (partial and full match)
* 🔤 Sort films by title (ascending/descending)
* ⭐ Filter films by your rating (0-10)
* 👁️ Filter films by watched status (Y/N)
* ➕ Add new films from OMDb API
* 📱 Movie details view with poster, plot, genre, year
* ✏️ Edit your rating and watched status for each film
* 🎥 Poster images fetched from OMDb API

## Requirements

* Android 8.0 (API Level 26) and above
* Android Studio
* Kotlin
* SQLite database (BongyFilms.db)
